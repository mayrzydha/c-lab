# C Lab

I use this repository as a personal lab for learning, practicing, and
experimenting with C. It contains notes, exercises, small experiments,
and projects I create while learning the language.

The `exercises/` directory contains my solutions to exercises from the
books and resources I use while learning C.

The `experiments/` directory contains small programs I write to explore
specific C concepts such as pointers, memory management, arrays, strings,
structs, file I/O, and the C memory model.

The `projects/` directory contains larger programs that combine concepts
I've learned along the way.
